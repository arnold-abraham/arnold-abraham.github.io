# arnold-abraham.github.io

Personal site (GitHub Pages).

## Projects section (pinned repos)

The **Projects** section is populated from a local JSON file:

- `assets/data/projects.json`

To keep it stable (no client-side GitHub API calls / no HTML scraping), the JSON is generated by a GitHub Action:

- Workflow: `.github/workflows/update-projects.yml`

### How to update pinned projects

1. Pin the repositories you want on your GitHub profile.
2. In this repo on GitHub, go to **Actions** → **Update pinned projects JSON** → **Run workflow**.
   - It also runs on a weekly schedule.

### Run locally (optional)

If you want to generate `projects.json` on your machine:

```bash
export GH_TOKEN="<your_github_token>"
export USERNAME="arnold-abraham"
python3 scripts/update_projects.py
```

Then open `index.html` via a local server.
